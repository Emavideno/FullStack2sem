Часть 2. Последовательность создания файлов
Порядок	Файл	Что делает
1	autoload.php	Загружает классы автоматически по PSR-4
2	src/Router.php	Анализирует URL, вызывает нужный контроллер
3	src/AbstractController.php	Базовый класс с общими методами (render, jsonResponse, redirect)
4	src/routes.php	Возвращает массив всех маршрутов (метод, URL, контроллер, действие)
5	public/index.php	Подключает автозагрузку, загружает маршруты, запускает роутер
6	src/Controllers/*.php	Контроллеры для каждой страницы (наследуются от AbstractController)
7	views/**/*.php	HTML-шаблоны с минимальными вставками PHP





Часть 3. Что должен делать роутер
Роутер — центральный элемент. Его задачи:

Хранить список зарегистрированных маршрутов

Определять текущий HTTP метод (GET, POST)

Извлекать параметры из URL (например, /news/123 → id=123)

Сравнивать запрошенный URL с маршрутами

Собирать данные запроса в один массив ($_GET, $_POST, заголовки, JSON тело)

Вызывать нужный метод контроллера, передавая ему данные запроса

Обрабатывать ситуацию, когда маршрут не найден (404)




Часть 4. Что должен делать абстрактный контроллер
Общий функционал для всех контроллеров:

Метод	Назначение
render()	Подключить HTML-шаблон, передать в него данные
jsonResponse()	Отправить JSON ответ (для API и AJAX)
redirect()	Перенаправить на другой URL
getRequestParam()	Безопасно получить параметр из запроса
getAllQueryParams()	Получить все GET параметры
getPostData()	Получить все POST данные
getJsonData()	Получить данные из JSON тела запроса
isAjaxRequest()	Проверить, AJAX ли запрос

Часть 6. Как запустить проект (без Apache)
Используйте встроенный PHP сервер:

bash
cd public
php -S localhost:5050
Что нужно знать:

Сервер запускается из папки public

Все запросы идут в index.php

Статические файлы (CSS, JS, изображения) отдаются автоматически

Перезапускать после изменения кода не нужно — PHP сам перезагружает файлы

Альтернативный способ (с роутерным файлом):

bash
php -S localhost:5050 router.php





Часть 7. Как организовать HTML (views)
Важно: у вас не будет чистых .html файлов. Вместо них — .php файлы, содержащие HTML с минимальными вставками PHP.

Что входит в каждый view-файл:

Обычный HTML код

Вставки данных через <?= $переменная ?>

Циклы <?php foreach(...): ?> ... <?php endforeach; ?>

Условные операторы <?php if(...): ?> ... <?php endif; ?>

Что НЕ должно быть в view-файлах:

Запросы к базе данных

Сложная бизнес-логика

Обработка форм

Сессии и куки

Общий шаблон (layout):

Создайте views/layouts/main.php с общим header/footer

Внутри него — место для контента <?= $content ?>

В контроллере можно использовать layout или рендерить отдельные шаблоны
