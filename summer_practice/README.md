# Географическая викторина

Веб-приложение для проверки знаний о странах мира в формате викторины с 6 режимами игры, статистикой и админ-панелью.

## Требования

- PHP 8.2+
- SQLite (или MySQL/PostgreSQL)
- Composer

## Быстрый старт

### 1. Клонирование и установка

```bash
git clone <repository-url>
cd summer_practice
php composer.phar install
cp config/.env.example config/.env
```

### 2. Импорт данных

```bash
php import.php
php generate-questions.php
php create-admin.php admin your_password
```

### 3. Запуск сервера

```bash
php -S localhost:8000 -t public
```

Откройте http://localhost:8000

## Режимы игры

| Режим | Описание |
|-------|----------|
| Угадай по флагу | Определите страну по её флагу |
| Угадай флаг | Найдите правильный флаг для страны |
| Страна по столице | Угадайте страну по её столице |
| Столица по стране | Назовите столицу страны |
| По населению | Угадайте страну по численности населения |
| По площади | Угадайте страну по территории |

## Статистика

- Личная статистика - общая успеваемость, процент правильных ответов
- Сильные и слабые регионы - анализ по частям света
- Тренировка слабых регионов - игра только по проблемным регионам
- Глобальный лидерборд - рейтинг всех пользователей
- Фильтрация по типам игр - сравнение по конкретным режимам

## Админ-панель

Доступна по адресу `/admin` для пользователей с ролью `admin`.

- Управление пользователями: блокировка и разблокировка
- Статистика пользователей: количество игр, правильных ответов, процент
- Обновление данных: импорт стран из API с проверкой актуальности 24 часа
- Мониторинг: количество стран и вопросов в базе

## Консольные команды

| Команда | Описание |
|---------|----------|
| `php import.php` | Импорт стран из API (проверяет актуальность) |
| `php import.php --force` | Принудительный импорт стран |
| `php generate-questions.php` | Генерация вопросов (6 типов) |
| `php clean-history.php [days]` | Очистка истории старше N дней (по умолчанию 30) |
| `php create-admin.php <login> <password>` | Создание администратора |

## Проверка CSRF-защиты

CSRF-токен успешно генерируется и сохраняется в сессии. Теперь нужно проверить, что он работает в формах.

### Проверка входа

1. Откройте страницу входа: http://localhost:8000/login
2. Посмотрите HTML-код формы - должен быть скрытый input с `name="csrf_token"`
3. Попробуйте войти с правильными данными - должно работать
4. Попробуйте удалить токен из формы - должна быть ошибка 403

### Проверка регистрации

Аналогично проверьте страницу регистрации.

### Проверка админки

1. Войдите как администратор
2. Попробуйте заблокировать пользователя
3. Должна быть проверка CSRF

В `app.log` и 'requests.log' видно, что логирование работает - записываются запросы и 404 ошибки.
