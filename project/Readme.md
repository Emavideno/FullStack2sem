# IT'sNews — агрегатор IT-новостей

Веб-приложение для агрегации новостей из мира информационных технологий. Пользователи могут просматривать ленту новостей, фильтровать по категориям, искать, оставлять комментарии и ставить реакции. Администратор управляет новостями и комментариями, а также может запускать парсинг RSS-лент.

---

## Требования

- PHP 8.4+
- SQLite
- Composer

---

## Установка и запуск

1. **Клонируйте репозиторий**
2. **Установите зависимости:**
   php composer.phar install
3. **Настройте окружение:**
   - Скопируйте `config/.env.example` в `config/.env`
   - При необходимости измените параметры
4. **Запустите сервер:**
   cd public
   php -S localhost:8000
5. **Откройте в браузере:** `http://localhost:8080`

---

## Админ-панель

| Параметр | Значение |
|----------|----------|
| URL | `/admin/news` |
| Логин | `admin` |
| Пароль | `admin` |

**Возможности администратора:**
- CRUD новостей
- Управление комментариями
- Парсинг RSS (Habr, Tproger)

---

## Основные функции

- Лента новостей с пагинацией
- Фильтрация по категориям (AJAX)
- Поиск по заголовку и тексту
- Просмотр полной(относительно) новости
- Комментарии (добавление через AJAX)
- Реакции (5 типов: 👍, ❤️, 🔥, 😊, 😢)

## Парсинг RSS

1. Войдите в админ-панель
2. Нажмите **RSS** → **Запустить парсинг**
3. Новости загрузятся с Habr и Tproger
